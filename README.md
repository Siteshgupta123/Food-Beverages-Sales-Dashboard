# 🥗 Food & Beverages Sales Dashboard 📊
**📊 Project Overview:**
- The Food and Beverage Sales Analysis Dashboard is an interactive Power BI project that provides key insights into sales performance, product categories, revenue channels, and salesperson efficiency. The dashboard enables businesses to monitor trends, identify top-performing products, and optimize strategies based on revenue and order data.

__________________________________________________________________________________________________
**🧠 Objective:**
The main goal of this project is to:
- Analyze revenue and order trends across time (monthly and quarterly)
- Understand performance of various sales channels (Retail, Online, Distributor)
- Identify top-selling products and product categories
- Evaluate salesperson contribution toward revenue and orders
- Help business stakeholders make data-driven decisions
